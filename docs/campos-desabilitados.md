# Mapa de campos desabilitados

Levantamento automático de `disabled={...}` fora de botões. Classificação:
`disabled={readOnly}` = Visualização; `disabled={disabled}` em wrappers é repasse (a causa real está em quem usa o wrapper); o resto é Bloqueio condicional.

Concluído: token `--field-disabled` aplicado em Input, Textarea, InputGroup, Select, Combobox e Checkbox. Campos de entidade já viram `readOnly` internamente; Checkbox/Select permanecem `disabled` (sem semântica de somente leitura).
